# 全司房源价格管理核对工作台

固定主链接：https://heifengzhaimogu-wq.github.io/-/price-desk/

演示：https://heifengzhaimogu-wq.github.io/-/price-desk/?demo=1

## 使用

正式入口点击“登录”，使用已开通的邮箱账号与密码。未授权账号看不到房源。演示模式只有虚构数据，修改不保存至服务器。

BP 查看全部数据并导入；店总仅查看本店；经理仅查看本店指定小组。授权信息存储在受保护的 price_members 中，RLS 在数据库执行。

导入第一张工作表，表头：编号、店面、小组、楼盘、房间号、报价、底价。编号和房间号请设为文本，金额以元为单位。最多 5000 行、10MB，按编号增量更新，不删除文件未包含的房源。价格改变后重新待核对，未变化记录保留核对状态。归属或楼盘房号变更会取消整批导入，避免误调房源。预览之后若数据库版本变化，整批取消并提示重新上传。

价格无误时点击对勾；修正时点击编辑按钮并填写原因。修改即时保存到 Supabase，其他已授权用户刷新即可获取。变更明细记录前后金额及差额。图片导出范围为当前筛选的当前页，可下载 PNG 或在兼容浏览器复制。

权限管理可添加、更新邮箱角色与范围，也可停用邮箱。添加授权不等于创建 Auth 登录账号，首次账号开通仍需由交付代理在获得 BP 邮箱及账号授权后完成。不要填写虚构管理员邮箱到生产权限表。

## 维护

源代码位于本目录的 source/，数据库定义 database.sql 与安全测试 tests/security.sql 随源码保存。npm ci 后执行 npm test 和 npm run build，更新本目录前端发布文件，继续使用同一 URL。前端只使用 publishable key，数据库密码和 service_role 不得加入仓库。原始 Excel 不上传至公开 GitHub，导入仅提交解析后的数据。

目前未实现原始文件云端存档、批量账号开通、PDF 导出或自动生成话术。

## 各店进度与 BP 店组管理

总览新增各店核对进度，口径为（已确认＋已修正）/ 本店房源总数。零房源店显示横线，不显示虚假的 100%。店总仅看到本店进度，店经理仅看到本组范围的进度；总览数字不受下方明细筛选影响。

BP 可从“店组管理”新增店面和小组、删除没有房源及授权成员的空店组，并搜索房源后点击“调整资料”。该入口可修改店面、小组、楼盘、房间号、报价和底价，要求填写原因，保存后重新待核对。房源编号保持稳定。归属与资料调整保留原值、新值、操作人和时间，店组管理底部可查看记录；单独的价格调整也保留在价格变更明细中。

目标店组须先创建；不会随着单套房源调组而调整任何员工的访问范围。需调整员工范围时由 BP 使用“权限管理”。转组后的原店组不再能查询该房源及其历史，跨组调整记录仅 BP 可见。

新增数据库升级脚本为 database-org-upgrade.sql，恢复到空数据库时先运行 database.sql，再运行该升级脚本。权限与数据版本由数据库校验，前端按钮隐藏不承担授权。

## Excel 导出与三级权限

总览顶部点击“导出表格”，可选择全司房源（仅 BP）、按店面，或当前筛选结果的全部页。文件含“房源明细”和“店面核对进度”两个工作表；房源编号和房号保留文本格式，金额为数字。演示文件名标注“演示数据”。店总的全部范围仅本店，店经理仅对应小组，不能导出其他店组的数据。

正式导出会重新验证登录身份及有效授权，再从受 RLS 保护的数据表分页获取最新数据；未授权或停用账号不能导出。角色代码 hrbp / store / team 保持兼容，页面显示为 BP / 店总 / 店经理。全司、店面和小组范围同时约束明细、进度、图片及 Excel 导出。首次正式账号开通和真实设备同步验收仍待收到 BP 邮箱及人员权限清单后完成。
