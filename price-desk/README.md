# 全私房源价格管理核对调整台

固定主链接：https://heifengzhaimogu-wq.github.io/-/price-desk/

演示：https://heifengzhaimogu-wq.github.io/-/price-desk/?demo=1

## 使用

正式入口点击“登录”，使用已开通的邮箱账号与密码。未授权账号看不到房源。演示模式只有虚构数据，修改不保存至服务器。

HRBP 查看全部数据并导入；店总仅查看本店；经理仅查看本店指定小组。授权信息存储在受保护的 price_members 中，RLS 在数据库执行。

导入第一张工作表，表头：编号、店面、小组、楼盘、房间号、报价、底价。编号和房间号请设为文本，金额以元为单位。最多 5000 行、10MB，按编号增量更新，不删除文件未包含的房源。价格改变后重新待核对，未变化记录保留核对状态。归属或楼盘房号变更会取消整批导入，避免误调房源。预览之后若数据库版本变化，整批取消并提示重新上传。

价格无误时点击对勾；修正时点击编辑按钮并填写原因。修改即时保存到 Supabase，其他已授权用户刷新即可获取。变更明细记录前后金额及差额。图片导出范围为当前筛选的当前页，可下载 PNG 或在兼容浏览器复制。

权限管理可添加、更新邮箱角色与范围，也可停用邮箱。添加授权不等于创建 Auth 登录账号，首次账号开通仍需由交付代理在获得 HRBP 邮箱及账号授权后完成。不要填写虚构管理员邮箱到生产权限表。

## 交付状态

前端和数据库结构已实现。真实房源、初始 HRBP 邮箱与员工权限清单尚未收到，因此不预置正式管理员、不导入演示数据至数据库。真实账号登录与两台设备之间同步验收待账号开通后完成。数据库角色隔离和写入版本冲突已通过事务内角色模拟测试。现有项目其他 schema 未改动。

## 维护

源代码位于本目录的 source/，数据库定义 database.sql 与安全测试 tests/security.sql 随源码保存。npm ci 后执行 npm test 和 npm run build，更新本目录三个前端发布文件，继续使用同一 URL。前端只使用 publishable key，数据库密码和 service_role 不得加入仓库。原始 Excel 不上传至公开 GitHub，导入仅提交解析后的数据。

目前未实现原始文件云端存档、批量账号开通、PDF 导出或自动生成话术。
